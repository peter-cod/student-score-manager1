# Student Score Manager

A beginner-friendly student score management website built with HTML, CSS and JavaScript. It demonstrates arrays, loops, searching, adding/deleting records, grades, totals, averages, and highest score.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Sign in at https://github.com/
2. Create a new **public** repository, for example `student-score-manager`.
3. Upload `index.html` and `README.md` to the repository root and commit the changes.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then click **Save**.
7. Wait a few minutes and open the URL shown in the Pages section. It usually looks like:
   `https://YOUR-USERNAME.github.io/student-score-manager/`

## Important
GitHub Pages hosts static websites. This project runs in the browser and does not require PHP or a database. The example student records are held in a JavaScript array and reset when the page is refreshed. Do not use real/private student data in this demo.
